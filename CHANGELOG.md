# Журнал изменений hideMyLute

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версии следуют семантическому версионированию `MAJOR.MINOR.PATCH`, где
`PATCH` равен количеству изменений с предыдущего минорного релиза
(см. `hideMyLute/_version.py`).

## [3.1.1] — 2026-08-05

### Добавлено

- Автоматический инкремент PATCH-версии при каждом пуше в `main`:
  скрипт `scripts/bump_version.py` обновляет `hideMyLute/_version.py`,
  `pyproject.toml` и `CHANGELOG.md`, а джоб сборки в CI фиксирует
  уникальную версию коммитом с `[skip ci]`, чтобы теги сборок не
  повторялись.

### Изменено

- Политика паролей для операции «Соединение» повышена до 12 символов.
- Статус-бар переведён на двухстрочный режим: текст статуса и
  кликабельный путь разделены; длинные пути усекаются в формате
  `[drive]:\...\[filename]`.

### Исправлено

- Путь результирующего файла больше не дублируется в текст статуса
  в панелях «Соединение» и «Разделение», передаётся через `click_path`.

## [3.1.0] — 2026-08-03

### Добавлено

- Автоматическая публикация GitHub Release по тегам `v*`: к релизу
  прикрепляется собранный `hideMyLute.exe` и заметки из `CHANGELOG.md`.

### Исправлено

- Санитизация имени контейнера для обоих разделителей путей (POSIX
  и Windows): недопустимые символы пути не ломают сохранение носителя.
- Корректная сборка exe в CI: удалены из индекса бинарники и
  аудит-отчёт; спецификация PyInstaller работает в чистом окружении.

### Прочее

- Минимальный `README.md`; обновлены описания в метаданных.

## [3.0.0] — 2026-08-02

### Изменено (несовместимо)

- **Формат футера v2**: magic-поле заголовка заполняется случайными
  байтами — файлы не содержат детектируемой сигнатуры `HMLF`
  (усиление правдоподобного отрицания); файлы v1 по-прежнему читаются.
- **Метаданные футера**: добавлен `container_hash_sha256` (целостность
  контейнера) и `container_name` (восстановление имени при разделении);
  `timestamp` удалён из метаданных.
- **Парольная политика**: минимальная длина пароля для операции
  «Соединение» — 12 символов; добавлено ограничение максимальной длины.

### Добавлено

- CLI-подкоманды `join` / `split` / `info` (`python -m hideMyLute ...`).
- Атомарность join/split: запись во временный файл + публикация через
  rename; очистка частичных файлов при ошибке и отмене операции.
- Потокобезопасная доставка callbacks из фонового потока (совместимость
  с Python 3.14, где `root.after` из чужого потока запрещён).
- Проверка целостности контейнера при разделении.
- Восстановление имени и расширения контейнера при разделении.
- Логирование операций join/split (размеры, длительность, результат).
- Конфигурация через переменные окружения `HIDEMYLUTE_*`.
- GitHub Actions CI (тесты с покрытием ≥ 80% + сборка exe).
- `pyproject.toml`, версионируемая спецификация сборки `hideMyLute.spec`,
  скрипт сборки `scripts/build.ps1`.

### Исправлено

- `setup_logging` вызывался некорректно: логирование включалось вопреки
  `logging_enabled=False`; теперь «режим без следов» работает.
- Необработанный `OSError` на файлах короче 12 байт при разделении.
- Гонка в `BackgroundWorker` (затирание ссылки на новый поток).
- TOCTOU между копированием носителя и вычислением хеша.
- Переключение языка через приватные атрибуты CustomTkinter заменено
  на публичный API.

## [2.0.4] — 2026-08-02

### Добавлено

- Автономный исполняемый файл `dist/hideMyLute.exe`, собранный
  PyInstaller (`--onefile --windowed`). Работает без установленного
  Python, не создаёт дополнительных файлов при работе и не оставляет
  следов (логирование отключено).
- Точка входа для сборки `launcher.py` и спецификация
  `hideMyLute.spec`.

## [2.0.3] — 2026-08-02

### Исправлено

- Выравнивание полей вкладки «Соединение», валидация статус-бара и
  перевод сообщений об ошибках.
- Значения по умолчанию в полях `AppConfig` (безопасный запуск без
  явной конфигурации).

### Добавлено

- Оценка надёжности пароля (слабая/приемлемая/надёжная) с индикацией
  в UI.
- Переключение языка интерфейса (русский/английский) в рантайме.
- Модуль версионирования `_version.py` и флаг командной строки
  `--version`.

## [2.0.0] — 2026-08-02

### Добавлено

- Полный рефакторинг в модульный пакет `hideMyLute`.
- Зашифрованный футер (`AES-256-GCM`) вместо внешнего лог-файла
  `steganography_log.dat`.
- `PBKDF2-HMAC-SHA256` с 600 000 итераций (OWASP 2023).
- Проверка целостности носителя по `SHA-256` при разделении.
- Потоковое копирование файлов (буфер 1 МБ).
- GUI на CustomTkinter: вкладки «Соединение» и «Разделение»,
  фоновый воркер, прогресс-бар.
- Три стратегии именования выходного файла: `WINDOWS_STYLE`, `UUID`,
  `SAME_AS_CARRIER`.
- Набор тестов `pytest` (71+ тестов) и настройка `ruff`.
